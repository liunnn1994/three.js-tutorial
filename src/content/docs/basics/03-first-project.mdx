## 为什么不能直接双击打开 HTML

如果你之前做过网页开发，可能习惯双击 HTML 文件在浏览器中打开。但在 Three.js 项目中，**千万不要这样做**。

这是因为浏览器以 `file://` 协议打开本地文件时，会施加严格的安全限制。许多 JavaScript 功能（尤其是 ES Module 的 `import` 语句）将无法正常工作。你的代码可能会报类似这样的错误：

```
Uncaught SyntaxError: Cannot use import statement outside a module
Access to script at 'file:///...' from origin 'null' has been blocked by CORS policy
```

这些安全限制是有道理的——你不会希望随便一个网页文件就能偷偷读取你电脑上的文件、打开摄像头、或者发送数据到某个服务器。

**解决方案**：我们需要一个**本地开发服务器**（Local Development Server），通过 HTTP 协议来提供文件，就像一个真正的网站一样运行。目前最佳方案是使用 **构建工具（Build Tool）**，它既能提供本地服务器，又能做很多其他有用的事情。

## Node.js 与 npm

### 什么是 Node.js

[Node.js](https://nodejs.org/) 是一个让 JavaScript 可以在**浏览器之外**运行的环境。在 Node.js 出现之前，JavaScript 只能在浏览器的网页中运行。有了 Node.js 之后，你可以在终端（命令行）中运行 JavaScript，甚至用它来构建桌面应用、服务器后端等等。

在 Three.js 开发中，我们需要 Node.js 来运行 Vite（构建工具）。当你安装 Node.js 时，它会自动帮你安装两个命令行工具：

- `node` — 执行 JavaScript 的运行时环境
- `npm` — Node Package Manager（Node 包管理器），用来安装和管理第三方库

:::tip
要验证你是否已安装 Node.js，在终端中输入 `node -v` 并按回车。如果显示版本号（如 `v20.11.0`），说明已经安装成功。如果提示"命令未找到"，请去 [Node.js 官网](https://nodejs.org/) 下载 **LTS 版本**（Long Term Support，长期支持版本）安装。
:::

### 什么是 npm

[npm](https://www.npmjs.com/)（Node Package Manager）是全球最大的 JavaScript 包仓库。你可以把它想象成一个"应用商店"——上面有数以百万计的开源代码库可以免费使用。

Three.js 和 Vite 都发布在 npm 上，我们通过 npm 命令来安装它们。npm 会自动处理**依赖关系**（Dependencies）：当 Vite 需要其他辅助库时，npm 会一并帮你下载。

npm 的核心命令：

| 命令                    | 说明                                         |
| ----------------------- | -------------------------------------------- |
| `npm init -y`           | 初始化一个 Node.js 项目，创建 `package.json` |
| `npm install <包名>`    | 安装某个包（如 `npm install three`）         |
| `npm install -D <包名>` | 安装开发依赖（只在开发时需要）               |
| `npm run <脚本名>`      | 运行 `package.json` 中定义的脚本命令         |

:::note[推荐阅读]

- [npm 官方文档 - 入门指南](https://docs.npmjs.com/getting-started)
- [Node.js 官方文档](https://nodejs.org/docs/latest/api/)
  :::

## 构建工具与 Vite

### 什么是构建工具

构建工具（Build Tool）是现代前端开发的"瑞士军刀"。它的核心功能包括：

1. **本地开发服务器** — 在本地启动一个 HTTP 服务器，自动监听文件变化并热更新
2. **模块打包** — 把你分散的多个 JS/CSS 文件合并优化
3. **代码转译** — 把新版 JavaScript 语法转成浏览器能兼容的旧版语法
4. **资源优化** — 压缩代码、处理图片、添加缓存哈希等
5. **生产构建** — 生成可以部署到服务器的最终文件

### 为什么选择 Vite

构建工具的"江湖"中有许多选择：Webpack、Parcel、Rollup、esbuild 等等。我们选择 [Vite](https://vitejs.dev/)（法语发音"Vite"，意思是"快"），原因如下：

- **极快的启动速度** — Vite 使用浏览器原生 ES Module，冷启动几乎瞬间完成
- **即时热更新（HMR）** — 修改代码后浏览器几乎无延迟地更新，体验丝滑
- **配置简单** — 开箱即用，不需要写复杂的配置文件
- **安装轻量** — 安装体积远小于 Webpack
- **稳定可靠** — 相比 Webpack，Vite 遇到的兼容性问题和 Bug 更少
- **由 Vue.js 作者开发** — Evan You 是前端界的知名开发者，社区活跃

:::note[对比参考]

- [Vite vs Webpack 官方对比](https://vitejs.dev/guide/comparisons.html)
- [Vite 为什么这么快？](https://vitejs.dev/guide/why.html)
- Vite 诞生前，Webpack 是最流行的构建工具，但它的配置文件（`webpack.config.js`）通常非常冗长复杂
  :::

## 终端基础

在开始搭建项目之前，你需要了解一些基本的终端命令。终端（Terminal）就像一个"文字版的文件管理器"——你可以用它来浏览文件夹、运行命令。

### 三个核心命令

| 命令  | 全称                    | 说明                                 | 示例                       |
| ----- | ----------------------- | ------------------------------------ | -------------------------- |
| `pwd` | Print Working Directory | 显示你当前所在的文件夹路径           | `/Users/yourname/projects` |
| `ls`  | List                    | 列出当前文件夹中的所有文件和子文件夹 | `ls`                       |
| `cd`  | Change Directory        | 切换到另一个文件夹                   | `cd my-project`            |

常用技巧：

- `cd ..` — 返回上一级文件夹
- `cd <文件夹名>` — 进入某个子文件夹（输入前面几个字母后按 **Tab** 键可以自动补全）
- 小技巧：在 VS Code 中，你可以输入 `cd `（注意空格），然后**拖拽文件夹到终端**自动填入路径

:::tip
推荐使用 [VS Code](https://code.visualstudio.com/) 作为代码编辑器。它内置了终端，按 `Ctrl + J`（Windows）或 `Cmd + J`（Mac）即可打开/关闭。VS Code 的内置终端非常好用，并且和你的项目文件夹自动关联。
:::

## 项目搭建（完整步骤）

### 第一步：创建项目文件夹

首先创建一个文件夹来存放你的项目。你可以用文件管理器（Finder / 资源管理器）创建，但推荐在 VS Code 中创建：

```
03-first-threejs-project/
```

### 第二步：初始化 Node.js 项目

打开终端，确保你进入了项目文件夹，然后运行：

```bash
npm init -y
```

这会创建一个 `package.json` 文件。`-y` 参数表示使用默认值（跳过交互式问答）。这个文件是 Node.js 项目的"身份证"，记录了项目名称、版本、依赖等信息。

执行后你的 `package.json` 看起来大致如下：

```json
{
  "name": "03-first-threejs-project",
  "version": "1.0.0",
  "description": "",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "keywords": [],
  "author": "",
  "license": "ISC"
}
```

### 第三步：安装 Vite 和 Three.js

```bash
npm install -D vite
npm install three
```

第一条命令安装 Vite 作为**开发依赖**（`-D` 标志），因为 Vite 只在开发时使用，最终网站不需要它。第二条命令安装 Three.js 作为**生产依赖**，因为 Three.js 是运行时需要的。

:::note 为什么 Vite 是开发依赖，Three.js 是生产依赖？

- **开发依赖**（`devDependencies`）：只在开发和构建阶段需要，最终产物不需要。就像建房子时用的脚手架——房子建好了脚手架就撤走了。
- **生产依赖**（`dependencies`）：最终网站运行时也需要。就像房子里的家具——房子交给住户时必须带着。
  :::

安装完成后，你会注意到项目中多了两个东西：

1. **`node_modules/` 文件夹** — 存放所有下载的依赖包代码。**不要手动修改里面的任何东西**，也不要把这个文件夹提交到版本控制（git）。
2. **`package-lock.json` 文件** — 记录了安装的每个依赖包的**精确版本号**。这确保了团队中每个人安装的版本完全一致。

### 第四步：配置 package.json 中的脚本

打开 `package.json`，把 `scripts` 部分修改为：

```json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  }
}
```

这样你就可以通过 `npm run dev` 来启动开发服务器，通过 `npm run build` 来构建生产版本。

:::caution[JSON 格式注意]
`package.json` 是 JSON 格式，非常严格：

- 所有键和字符串值必须用**双引号**包裹
- **不能有尾逗号**（最后一项后面不能加逗号）
- 不能有注释
  如果格式错误，后续的 `npm` 命令都会报错
  :::

### 第五步：创建 HTML 文件

在项目根目录下创建 `index.html`（推荐通过 VS Code 创建，而不是系统文件管理器，因为后者可能会隐藏文件扩展名）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>我的第一个 Three.js 项目</title>
    <link rel="stylesheet" href="./style.css" />
  </head>
  <body>
    <canvas class="webgl"></canvas>
    <script type="module" src="./script.js"></script>
  </body>
</html>
```

**关键要点**：

- `<canvas class="webgl"></canvas>` — 这是 Three.js 的渲染画布。我们用一个 `class="webgl"` 来让 JavaScript 能精确地找到这个 canvas 元素。
- `<script type="module" src="./script.js"></script>` — 注意 `type="module"` 属性。这告诉浏览器这是一个 ES Module 脚本，允许我们使用 `import` 语句来导入 Three.js。如果没有这个属性，`import` 会报错。

:::caution[不要双击打开 HTML]
再次提醒：**不要**双击 `index.html` 在浏览器中打开。我们必须通过 Vite 的开发服务器来运行它。
:::

### 第六步：创建 JavaScript 文件

创建 `script.js`，先写一个简单的测试：

```js
console.log("JavaScript is working!");
```

### 第七步：启动开发服务器

在终端中运行：

```bash
npm run dev
```

Vite 会启动一个本地服务器，终端会显示类似这样的输出：

```
  VITE v4.5.0  ready in 140 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.1.xxx:5173/
```

在浏览器中打开这个地址（通常是 `http://localhost:5173`），然后按 **F12** 打开开发者工具（DevTools），切换到 Console 标签，你应该能看到 `JavaScript is working!`。

:::tip[热更新（HMR）]
试试修改 `script.js` 中的文字并保存——浏览器会自动刷新，不需要你手动按 F5。这就是 Vite 的热更新功能，让你在开发时效率大幅提升。
:::

:::caution[终端被占用]
启动 `npm run dev` 后，终端看起来"卡住了"，因为服务器一直在后台运行。你可以在 VS Code 中点击终端面板的 `+` 按钮打开一个新的终端标签页来运行其他命令。要停止服务器，在运行 `dev` 的终端中按 `Ctrl + C`。
:::

## 安装 Three.js 并导入

运行以下命令安装 Three.js（如果之前已经安装过就跳过）：

```bash
npm install three
```

安装完成后，**需要重启服务器**（在终端中按 `Ctrl + C` 停止，再运行 `npm run dev`）。

现在修改 `script.js`，将第一行替换为：

```js
import * as THREE from "three";

console.log(THREE);
```

保存后打开浏览器的 Console，你会看到一个包含大量属性和方法的对象。这就是 Three.js 库的全部内容——它包含了创建 3D 场景所需的所有类和工具。

**导入语法解释**：

- `import * as THREE` — 把 Three.js 库的**所有导出内容**都导入到 `THREE` 这个变量中
- `from 'three'` — 从名为 `'three'` 的包导入。注意写的是 `'three'`（小写），而不是 `'Three'` 或 `'three.js'`，因为这是 npm 上的包名

:::note[ES Modules]
这种 `import`/`export` 语法叫做 **ES Modules**（ESM），是 JavaScript 官方的模块化方案。为了使用它，HTML 中的 `<script>` 标签必须添加 `type="module"` 属性。
:::

## 理解 Three.js 的四个核心要素

在开始写代码之前，你需要理解 Three.js 场景的四个核心组成部分。你可以把它想象成**拍一部电影**：

| Three.js 概念          | 电影类比               | 作用                                     |
| ---------------------- | ---------------------- | ---------------------------------------- |
| **Scene（场景）**      | 电影的整个布景/舞台    | 一个容器，存放所有 3D 物体、灯光等       |
| **Object（物体）**     | 舞台上的演员和道具     | 你想要展示的 3D 内容（立方体、模型等）   |
| **Camera（相机）**     | 拍摄影像机             | 决定观察角度和视野范围                   |
| **Renderer（渲染器）** | 负责最终出片的后期处理 | 把 3D 场景"拍成"一张 2D 图片显示在屏幕上 |

## 逐步创建场景

### 1. 获取 Canvas 元素

```js
// 获取 HTML 中的 canvas 元素
const canvas = document.querySelector("canvas.webgl");
```

`document.querySelector()` 是浏览器提供的 DOM API，它接受一个 CSS 选择器字符串。`'canvas.webgl'` 的意思是"选择一个 `<canvas>` 标签且具有 `class="webgl"` 的元素"。返回值是一个 DOM 元素对象，我们把它存到 `canvas` 变量中。

我们预先在 HTML 中创建 canvas，而不是让渲染器自动创建，这样我们可以在后续课程中更灵活地控制它（比如调整大小、获取上下文等）。

### 2. 创建场景

```js
// 创建场景
const scene = new THREE.Scene();
```

[Scene](https://threejs.org/docs/#api/en/scenes/Scene)（场景）是所有 3D 对象的容器。你可以把它想象成一个**空旷的舞台**——目前上面什么都没有。我们需要往上面放物体、灯光、相机等。

注意 `THREE` 必须全部大写，`Scene` 的 `S` 也必须大写（这叫 **PascalCase** 命名规范）。

### 3. 创建物体（Mesh = Geometry + Material）

在 Three.js 中，一个可见的 3D 物体叫做 **Mesh**（网格）。Mesh 由两部分组成：

- **Geometry（几何体）** — 定义物体的**形状**（它长什么样）
- **Material（材质）** — 定义物体的**外观**（它看起来什么样）

```js
/**
 * Object — 创建一个红色立方体
 */

// 1. 创建几何体（形状）：一个长宽高均为 1 的立方体
const geometry = new THREE.BoxGeometry(1, 1, 1);

// 2. 创建材质（外观）：纯红色、不受光照影响
const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });

// 3. 创建网格（Mesh）= 几何体 + 材质
const mesh = new THREE.Mesh(geometry, material);

// 4. 将网格添加到场景中
scene.add(mesh);
```

**逐行解释**：

**`BoxGeometry(1, 1, 1)`** — [BoxGeometry](https://threejs.org/docs/#api/en/geometries/BoxGeometry) 创建一个长方体（盒子）。三个参数分别是**宽度**（Width）、**高度**（Height）和**深度**（Depth），单位是 Three.js 内部单位（可以理解为"米"）。三个值都设为 1 就是一个完美的立方体。如果你想创建一个扁平的长方形，可以写成 `BoxGeometry(2, 0.5, 1)`。

**`MeshBasicMaterial({ color: 0xff0000 })`** — [MeshBasicMaterial](https://threejs.org/docs/#api/en/materials/MeshBasicMaterial) 是最简单的材质类型。它不受光照影响，只显示纯色——无论场景中有没有灯光，它都是同样的颜色。`color` 属性接受十六进制颜色值 `0xff0000`（红色）。你也可以用字符串 `'red'` 或 CSS 颜色字符串 `'#ff0000'`。

:::note 为什么是 `0xff0000`？
这是**十六进制颜色**的 JavaScript 写法。`0x` 前缀表示这是一个十六进制数。`ff0000` 中：`ff` = 红色（最大值），`00` = 绿色（无），`00` = 蓝色（无）。所以它是纯红色。
:::

**`new THREE.Mesh(geometry, material)`** — 把几何体和材质组合成一个可见的 3D 对象。

**`scene.add(mesh)`** — 将物体添加到场景中。这一步很关键——如果不添加，物体虽然被创建了，但不在场景中，渲染时看不到它。

### 4. 设置渲染尺寸

```js
/**
 * Sizes — 定义渲染画布的宽高
 */
const sizes = {
  width: 800,
  height: 600,
};
```

我们用 800 x 600 像素来渲染。后续课程中我们会改为使用窗口的完整大小来实现全屏效果。将尺寸存到对象中是因为我们在多个地方都需要用到（相机和渲染器），这样修改时只需改一个地方。

### 5. 创建相机

```js
/**
 * Camera — 创建透视相机
 */
const camera = new THREE.PerspectiveCamera(75, sizes.width / sizes.height);
camera.position.z = 3;
scene.add(camera);
```

[PerspectiveCamera](https://threejs.org/docs/#api/en/cameras/PerspectiveCamera)（透视相机）模拟人眼的视觉效果——近处的物体看起来大，远处的物体看起来小。

**两个必需参数**：

1. **`75`** — **FOV（Field of View，视场角）**，单位是度。这是垂直方向的视野角度。FOV 值越大，你能看到的范围越广（像广角镜头），但画面会有透视变形。值越小，视野越窄（像长焦/望远镜），画面更"平"。75 度是比较适中的值，适合学习。实际网站项目中，35 ~ 50 度更常见。记住一个完整圆周是 360 度。

2. **`sizes.width / sizes.height`** — **宽高比（Aspect Ratio）**。它告诉相机渲染区域是宽还是高。800 / 600 = 1.333，接近 4:3 的比例。如果这个值不正确，物体会被拉伸变形（比如圆形变成椭圆）。

**`camera.position.z = 3`** — 将相机向后移动 3 个单位。为什么需要这样做？因为在 Three.js 中，默认情况下所有物体（包括相机和立方体）都在坐标原点 `(0, 0, 0)` 处。如果相机和立方体在同一个位置，相机就在立方体"里面"了——而在 3D 中你无法看到物体的内部。我们需要把相机往后移，这样才能看到立方体的正面。

:::note Three.js 的坐标系
Three.js 使用**右手坐标系**：

- **X 轴** — 左右方向（正值 = 右，负值 = 左）
- **Y 轴** — 上下方向（正值 = 上，负值 = 下）
- **Z 轴** — 前后方向（正值 = 向你/向后，负值 = 远离你/向前）

这意味着 `camera.position.z = 3` 把相机向"你"的方向（即屏幕后方）移动了 3 个单位。从相机来看，立方体就在前方 3 个单位处。
:::

**`scene.add(camera)`** — 把相机也添加到场景中。虽然这一步在大多数情况下不是必须的（渲染器只需要相机对象，不需要它在场景中），但有些功能（比如某些相机辅助工具）依赖于相机在场景中，所以建议始终加上。

### 6. 创建渲染器并渲染

```js
/**
 * Renderer — 创建 WebGL 渲染器并执行第一次渲染
 */
const renderer = new THREE.WebGLRenderer({
  canvas: canvas,
});
renderer.setSize(sizes.width, sizes.height);
renderer.render(scene, camera);
```

**逐行解释**：

**`new THREE.WebGLRenderer({ canvas: canvas })`** — [WebGLRenderer](https://threejs.org/docs/#api/en/renderers/WebGLRenderer) 是 Three.js 的默认渲染器，它使用 WebGL 技术把 3D 场景渲染成 2D 图像。我们通过传入 `canvas` 参数，告诉渲染器把结果画在我们之前创建的 `<canvas>` 元素上（而不是自动创建一个新的 canvas 元素）。

注意参数是一个**对象** `{ canvas: canvas }`。在 JavaScript 中，如果对象属性的值和变量名相同，可以简写为 `{ canvas }`，但为了清晰起见，我们写完整的 `{ canvas: canvas }`。

**`renderer.setSize(sizes.width, sizes.height)`** — 设置渲染器的输出尺寸为 800 x 600 像素。这会同时修改 canvas 元素的宽高属性和 CSS 样式。

**`renderer.render(scene, camera)`** — 这是"拍照"的时刻。渲染器会从相机的视角对场景进行一次"拍摄"，把结果绘制到 canvas 上。这个方法会执行以下操作：

1. 从相机的位置和角度观察场景
2. 计算每个物体的投影
3. 在 canvas 上绘制最终像素

## 完整代码

以下是 `script.js` 的完整内容：

```js title="script.js"
import * as THREE from "three";

// Canvas — 获取 HTML 中的 canvas 元素
const canvas = document.querySelector("canvas.webgl");

// Scene — 创建场景（所有 3D 对象的容器）
const scene = new THREE.Scene();

/**
 * Object — 创建红色立方体
 */
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0xff0000 });
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

/**
 * Sizes — 渲染画布的尺寸
 */
const sizes = {
  width: 800,
  height: 600,
};

/**
 * Camera — 创建透视相机并移到后方
 */
const camera = new THREE.PerspectiveCamera(75, sizes.width / sizes.height);
camera.position.z = 3;
scene.add(camera);

/**
 * Renderer — 创建渲染器并执行渲染
 */
const renderer = new THREE.WebGLRenderer({
  canvas: canvas,
});
renderer.setSize(sizes.width, sizes.height);
renderer.render(scene, camera);
```
