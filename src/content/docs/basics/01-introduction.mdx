## 欢迎来到 Three.js 中文教程

本教程是适合前端开发者的完整 3D Web 开发课程，所有代码示例使用最新的(2026) Three.js API，带你从零开始掌握 Three.js 3D Web 开发。

### 什么是 Three.js

Three.js 是一个 JavaScript 3D 库，它让开发者能够在浏览器中创建 3D 体验。它封装了底层的 WebGL API，让创建 3D 场景、添加光照、加载模型、制作动画等操作变得简单直观。

**简单来说**：WebGL 是浏览器提供的底层图形接口（非常复杂），Three.js 在 WebGL 之上封装了一层友好的 API，让你用少量代码就能实现 3D 效果。

### Three.js 能做什么

Three.js 被广泛应用于以下场景：

- **产品展示网站** — 3D 产品旋转、交互展示（如汽车、手表、家具等）
- **创意作品集** — 令人印象深刻的个人主页
- **数据可视化** — 3D 图表、地图、科学模拟
- **游戏** — 基于 WebGL 的浏览器 3D 游戏
- **艺术与实验** — 粒子系统、着色器艺术、声音可视化
- **虚拟现实/增强现实** — WebXR 体验

在 [Three.js 官方案例](https://threejs.org/examples/) 中可以看到数百个精彩的演示项目。

## 课程结构

本教程共 53 课，分为五个章节，从零基础到实战项目：

### 第一章：基础入门（第 01-13 课）

学习 Three.js 的核心概念，搭建 3D 场景的基础能力：

- 场景、相机、渲染器的创建
- 几何体与材质
- 纹理贴图
- 动画系统
- 3D 文字
- 部署上线

### 第二章：经典技术（第 14-25 课）

掌握让 3D 场景更加丰富的技术：

- 光照与阴影
- 粒子系统
- 物理引擎
- 3D 模型导入
- 环境贴图与真实感渲染

### 第三章：着色器（第 26-44 课）

深入学习 GLSL 着色器编程，解锁 WebGL 的真正威力：

- 顶点着色器与片元着色器
- 着色器模式与技巧
- 海洋、银河、烟雾、全息图等实战效果
- GPGPU 与粒子系统

### 第四章：高级主题（第 45-48 课）

- 后处理效果（泛光、景深等）
- 性能优化
- HTML 与 WebGL 混合

### 第五章：场景创建（第 49-53 课）

完整的 Blender + Three.js 工作流项目，从建模到最终上线。

## 你需要准备什么

### 必备知识

- **JavaScript 基础** — 你需要了解变量、数组、对象、循环、函数和事件。不需要精通，只要能读懂基本代码即可
- **HTML 和 CSS 基础** — 了解网页的基本结构

### 你不需要

- 3D 图形学知识 — 本教程会从零讲解
- 高等数学 — 虽然向量、矩阵等概念会有帮助，但不是必须的，教程中会解释涉及的公式
- Three.js 或 WebGL 经验 — 本教程就是从零开始的
- React 或其他框架 — 本教程使用纯 JavaScript

### 开发环境

| 工具           | 说明                           | 推荐选择                                                                  |
| -------------- | ------------------------------ | ------------------------------------------------------------------------- |
| **电脑**       | 需要能安装和运行开发软件       | 任意操作系统均可                                                          |
| **代码编辑器** | 编写代码的工具                 | [Visual Studio Code](https://code.visualstudio.com/)（推荐）              |
| **浏览器**     | 调试和预览效果                 | [Chrome](https://www.google.com/chrome/) 或 Firefox（开发调试推荐这两款） |
| **Node.js**    | JavaScript 运行环境和包管理器  | [Node.js LTS 版本](https://nodejs.org/)                                   |
| **Blender**    | 免费 3D 建模软件（第五章使用） | [Blender](https://www.blender.org/)                                       |

:::caution
开发调试建议使用 Chrome 或 Firefox。避免使用 Brave 等带有严格隐私/安全功能的浏览器，它们可能会干扰代码的正常运行。
:::

## 学习建议

1. **按顺序学习** — 课程是按知识依赖关系编排的。如果跳过某些课后感到困惑，请回到前面的课程补齐知识
2. **动手实践** — 每课都提供练习代码（starter），跟着视频同步编码比单纯观看效果好得多
3. **不要着急** — 70 小时的内容需要时间消化，不是速通挑战。找到你一天中学习效率最高的时间段
4. **遇到困难别放弃** — 着色器等高级主题确实有难度，但这是正常的。教程会多次接触困难概念，每次都会加深理解
5. **不需要完成全部课程才能做项目** — 学完前一两章后，你就已经可以开始创建很酷的 3D 网站了
