## 什么是 @tresjs/cientos

`@tresjs/cientos` 是 TresJS 的辅助工具库，提供了大量开箱即用的组件，让你不必从零实现常见的 3D 功能。它涵盖控制器、环境布景、模型加载、材质、形状等几大分类。

```bash
npm install @tresjs/cientos
```

## 控制器

### OrbitControls

相机轨道控制器，允许用户通过鼠标拖拽旋转、缩放、平移场景：

```vue
<script setup>
import { OrbitControls } from "@tresjs/cientos";
</script>

<template>
  <TresCanvas>
    <OrbitControls
      :enable-damping="true"
      :damping-factor="0.05"
      :auto-rotate="true"
      :auto-rotate-speed="2"
    />
  </TresCanvas>
</template>
```

| 属性                                           | 说明                   | 默认值      |
| ---------------------------------------------- | ---------------------- | ----------- |
| `enable-damping`                               | 启用阻尼惯性           | `true`      |
| `damping-factor`                               | 阻尼系数               | `0.05`      |
| `auto-rotate`                                  | 自动旋转               | `false`     |
| `auto-rotate-speed`                            | 自动旋转速度           | `2`         |
| `min-distance` / `max-distance`                | 缩放距离限制           | —           |
| `enable-pan` / `enable-rotate` / `enable-zoom` | 启用/禁用操作          | `true`      |
| `target`                                       | 观察目标点 `[x, y, z]` | `[0, 0, 0]` |

### 其他控制器

| 组件                  | 说明                                                  |
| --------------------- | ----------------------------------------------------- |
| `MapControls`         | 地图风格控制器（类似 OrbitControls 但中键平移更直觉） |
| `TransformControls`   | 在场景中拖拽移动/旋转/缩放物体                        |
| `PointerLockControls` | 第一人称视角锁定鼠标控制                              |
| `KeyboardControls`    | 键盘输入控制                                          |

## HTML 叠加

### Html

在 3D 空间中嵌入 HTML 元素，适合做标签、信息面板等：

```vue
<script setup>
import { Html } from "@tresjs/cientos";
</script>

<template>
  <TresMesh>
    <TresSphereGeometry />
    <Html :position="[1, 1, 0]" center distance-factor="10">
      <div style="background: rgba(0,0,0,0.7); color: white; padding: 8px;">这是一个标签</div>
    </Html>
  </TresMesh>
</template>
```

| 属性              | 说明                                         |
| ----------------- | -------------------------------------------- |
| `center`          | 居中 HTML 内容                               |
| `distance-factor` | 根据距离自动缩放，让标签像"固定"在 3D 空间中 |
| `occlude`         | 遮挡设置，HTML 可被 3D 物体遮挡              |
| `transform`       | 启用 3D 变换模式                             |

## 文字

### Text

基于 troika-three-text 的文字渲染组件，渲染平面文字（始终面向相机），性能优秀：

```vue
<script setup>
import { Text } from "@tresjs/cientos";
</script>

<template>
  <Text text="Hello TresJS" color="salmon" :font-size="1" :position-y="2" />
</template>
```

### Text3D

基于 Three.js `TextGeometry` 的 3D 立体文字，有真正的厚度和倒角：

```vue
<script setup>
import { Text3D, Center } from "@tresjs/cientos";
</script>

<template>
  <Center>
    <Text3D font="/fonts/helvetiker_regular.typeface.json" :size="0.75" :height="0.2">
      Hello TresJS
    </Text3D>
  </Center>
</template>
```

:::tip
`Text` 适合 UI 文字标签，渲染快；`Text3D` 适合装饰性标题，视觉效果好但性能开销更大。
:::

## 动画与效果

### Levioso

让物体自动上下浮动，适合做装饰效果：

```vue
<script setup>
import { Levioso } from "@tresjs/cientos";
</script>

<template>
  <Levioso :speed="5" :float-factor="2" :rotation-factor="10">
    <TresMesh>
      <TresBoxGeometry />
      <TresMeshStandardMaterial color="orange" />
    </TresMesh>
  </Levioso>
</template>
```

| 属性              | 说明                      | 默认值 |
| ----------------- | ------------------------- | ------ |
| `speed`           | 浮动速度                  | `1`    |
| `float-factor`    | 浮动幅度                  | `1`    |
| `rotation-factor` | 旋转幅度                  | `0`    |
| `range`           | Y 轴浮动范围 `[min, max]` | —      |

### Billboard

让子物体始终面向相机：

```vue
<script setup>
import { Billboard } from "@tresjs/cientos";
</script>

<template>
  <Billboard>
    <TresMesh>
      <TresPlaneGeometry :args="[1, 0.5]" />
      <TresMeshBasicMaterial color="red" />
    </TresMesh>
  </Billboard>
</template>
```

## 简写形状组件

Cientos 为常用几何体提供了简写组件，省去手动添加 `TresMesh` + `TresXxxGeometry` 的步骤：

```vue
<script setup>
import { Box, Sphere, Torus, TorusKnot } from "@tresjs/cientos";
</script>

<template>
  <Box :args="[1, 1, 1]" color="mediumpurple" :position="[-2, 0, 0]" />
  <Sphere :args="[0.75, 32, 32]" color="orange" :position="[0, 0, 0]" />
  <Torus :args="[0.6, 0.25, 16, 32]" color="cyan" :position="[2, 0, 0]" />
</template>
```

所有简写形状都自带 `MeshStandardMaterial`，可直接通过 `color` 属性设置颜色。

可用形状：`Box`、`Sphere`、`Cone`、`Cylinder`、`Plane`、`Ring`、`Torus`、`TorusKnot`、`Dodecahedron`、`Icosahedron`、`Octahedron`、`Tetrahedron`、`RoundedBox` 等。

## 特色材质

Cientos 提供了几种开箱即用的特色材质：

| 组件                     | 说明             |
| ------------------------ | ---------------- |
| `HolographicMaterial`    | 全息投影效果材质 |
| `MeshGlassMaterial`      | 玻璃效果材质     |
| `MeshWobbleMaterial`     | 弹性变形效果材质 |
| `MeshReflectionMaterial` | 反射效果材质     |
| `CustomShaderMaterial`   | 自定义着色器材质 |

## 加载器

| 工具                         | 说明               |
| ---------------------------- | ------------------ |
| `useGLTF`                    | 加载 GLTF/GLB 模型 |
| `useFBX`                     | 加载 FBX 模型      |
| `useTexture` / `useTextures` | 加载单个/多个纹理  |
| `useVideoTexture`            | 加载视频纹理       |
| `useSVG`                     | 加载 SVG           |
| `useProgress`                | 跟踪加载进度       |

## 环境与布景

| 组件                  | 说明                               |
| --------------------- | ---------------------------------- |
| `Environment`         | 环境光照，快速添加 HDR 环境贴图    |
| `ContactShadows`      | 接触阴影，物体底部柔和阴影         |
| `Sky`                 | 天空盒                             |
| `Stars`               | 星空粒子                           |
| `Sparkles`            | 闪烁粒子效果                       |
| `Stage`               | 一键场景布景（光照 + 地面 + 环境） |
| `AccumulativeShadows` | 累积阴影，质量高                   |
| `Ocean`               | 海洋水面效果                       |
