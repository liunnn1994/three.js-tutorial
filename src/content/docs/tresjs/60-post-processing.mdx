## 什么是后处理

后处理（Post-Processing）是在 3D 场景渲染完成后，对最终图像进行额外处理的效果。常见的后处理效果包括辉光（Bloom）、暗角（Vignette）、景深（DOF）等。

### @tresjs/post-processing

```bash
npm install @tresjs/post-processing
```

TresJS 的后处理库基于 pmndrs/postprocessing 构建，提供了 30+ 种后处理效果组件。

## EffectComposerPmndrs

所有后处理效果都需要包裹在 `EffectComposerPmndrs` 中：

```vue
<script setup lang="ts">
import { EffectComposerPmndrs, BloomPmndrs, VignettePmndrs } from '@tresjs/post-processing'
</script>

<template>
  <TresCanvas>
    <!-- 3D 场景内容 -->

    <EffectComposerPmndrs>
      <BloomPmndrs :intensity="0.5" />
      <VignettePmndrs :offset="0.3" :darkness="0.8" />
    </EffectComposerPmndrs>
  </TresCanvas>
</template>
```

`EffectComposerPmndrs` 属性：

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `enabled` | 启用/禁用后处理 | `true` |
| `resolution-scale` | 渲染分辨率缩放 | — |
| `multisampling` | 多重采样抗锯齿 | — |
| `depth-buffer` | 启用深度缓冲 | `false` |
| `disable-normal-pass` | 禁用法线通道 | `false` |

:::tip
效果组件的排列顺序决定了渲染顺序——先列出的效果先生效。
:::

:::caution
后处理效果会增加 GPU 负担。在移动设备上，建议只使用必要的后处理效果，并通过 `resolution-scale` 降低渲染分辨率。
:::

## 常用效果

### 辉光 BloomPmndrs

让明亮区域产生光晕溢出效果：

```vue
<BloomPmndrs :intensity="1.5" :luminance-threshold="0.9" />
```

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `intensity` | 辉光强度 | `1` |
| `luminance-threshold` | 亮度阈值，超过才产生辉光 | `0.9` |
| `kernel-size` | 模糊核大小 | — |

### 暗角 VignettePmndrs

画面边缘变暗，聚焦中心：

```vue
<VignettePmndrs :offset="0.3" :darkness="0.8" />
```

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `offset` | 暗角起始偏移 | `0.5` |
| `darkness` | 暗角黑暗程度 | `0.5` |

### 景深 DepthOfFieldPmndrs

模拟相机景深效果，远处和近处模糊：

```vue
<DepthOfFieldPmndrs :focus-distance="0" :focal-length="0.02" :bokeh-scale="2" />
```

### 故障 GlitchPmndrs

数字故障效果，适合赛博朋克风格：

```vue
<GlitchPmndrs :delay="[3, 7]" :duration="[0.1, 0.3]" :strength="[0.1, 0.3]" />
```

## 色彩效果

| 组件 | 说明 |
|------|------|
| `BrightnessContrastPmndrs` | 亮度/对比度调节 |
| `HueSaturationPmndrs` | 色相/饱和度调节 |
| `SepiaPmndrs` | 怀旧棕褐色调 |
| `ToneMappingPmndrs` | 色调映射 |
| `ColorDepthPmndrs` | 色彩深度（像素化色彩） |

## 视觉风格效果

| 组件 | 说明 |
|------|------|
| `PixelationPmndrs` | 像素化 |
| `DotScreenPmndrs` | 半色调网点效果 |
| `ScanlinePmndrs` | 扫描线效果 |
| `GridPmndrs` | 网格效果 |
| `ASCIIPmndrs` | ASCII 字符画效果 |
| `NoisePmndrs` | 噪点效果 |

| 组件 | 说明 |
|------|------|
| `ChromaticAberrationPmndrs` | 色差（边缘色彩分离） |

| `LensDistortionPmndrs` | 镜头畸变 |

| `GodRaysPmndrs` | 上帝之光（体积光） |
| `OutlinePmndrs` | 物体轮廓描边 |

## 抗锯齿

| 组件 | 说明 |
|------|------|
| `SMAAPmndrs` | SMAA 抗锯齿 |
| `FXAAPmndrs` | FXAA 抗锯齿 |

:::tip
抗锯齿效果通常放在效果链的最后。如果 TresCanvas 已开启 `antialias`，一般不需要额外添加。
:::
