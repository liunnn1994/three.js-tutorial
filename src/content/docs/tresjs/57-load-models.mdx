## 加载 GLTF/GLB 模型

### useGLTF

`@tresjs/cientos` 提供的 `useGLTF` 用于加载 GLTF/GLB 格式的 3D 模型：

```vue
<script setup lang="ts">
import { useGLTF } from '@tresjs/cientos'

const { scene } = await useGLTF('/models/fox.glb')
</script>

<template>
  <primitive :object="scene" />
</template>
```

`useGLTF` 的完整选项：

```ts
const { scene, nodes, materials, animations } = await useGLTF('/model.glb', {
  draco: true,              // 启用 Draco 解压
  decoderPath: '/draco/',   // Draco 解码器路径
  castShadow: true,         // 模型投射阴影
  receiveShadow: true,      // 模型接收阴影
})
```

:::tip
解构返回的 `nodes` 和 `materials` 可以按名称访问模型的各个部件，`animations` 包含模型内置的动画数据。
:::

### Suspense 加载状态

由于模型加载是异步的，需要配合 Vue 的 `Suspense` 使用：

```vue
<template>
  <TresCanvas>
    <Suspense>
      <template #default>
        <MyModel />
      </template>
      <template #fallback>
        <TresMesh>
          <TresBoxGeometry />
          <TresMeshStandardMaterial color="gray" wireframe />
        </TresMesh>
      </template>
    </Suspense>
  </TresCanvas>
</template>
```

`Suspense` 的 `#fallback` 插槽会在模型加载期间显示，你可以在这里放一个简单的占位物体。

### Draco 压缩

Draco 是一种 3D 模型压缩格式，可以显著减小文件体积（通常压缩 70%-90%）：

```ts
// 启用 Draco 并使用默认解码器
const { scene } = await useGLTF('/model.glb', { draco: true })

// 或指定自定义 Draco 解码器路径
const { scene } = await useGLTF('/model.glb', {
  draco: '/draco/'
})
```

### 创建可复用的模型组件

```vue
<!-- LoadModel.vue -->
<script setup lang="ts">
import { useGLTF } from '@tresjs/cientos'

const props = defineProps<{
  modelPath: string
  scale?: number
  position?: [number, number, number]
}>()

const { scene } = await useGLTF(props.modelPath, { draco: true })
</script>

<template>
  <primitive :object="scene" :scale="scale" :position="position" />
</template>
```

## 纹理加载

### useTexture

加载纹理贴图：

```vue
<script setup lang="ts">
import { useTexture } from '@tresjs/cientos'

const map = await useTexture('/textures/wood.jpg')
</script>

<template>
  <TresMesh>
    <TresBoxGeometry />
    <TresMeshStandardMaterial :map="map" />
  </TresMesh>
</template>
```

### useTextures

批量加载多个纹理：

```ts
const [map, normalMap, roughnessMap] = await useTextures([
  '/textures/wood.jpg',
  '/textures/wood_normal.jpg',
  '/textures/wood_roughness.jpg',
])
```

### useVideoTexture

将视频作为纹理贴图：

```ts
const videoTexture = await useVideoTexture('/videos/background.mp4')
```

## 加载进度

### useProgress

跟踪场景中所有资源的加载进度：

```vue
<script setup>
import { useProgress } from '@tresjs/cientos'

const { progress, hasFinishLoading } = useProgress()
</script>

<template>
  <div v-if="!hasFinishLoading" class="loading">
    加载中... {{ Math.round(progress) }}%
  </div>
</template>
```

| 属性 | 说明 |
|------|------|
| `progress` | 加载进度（0-100） |
| `hasFinishLoading` | 是否全部加载完成 |
| `errors` | 加载失败的资源列表 |

## 其他加载器

| 工具 | 说明 |
|------|------|
| `useFBX` | 加载 FBX 格式模型 |
| `useSVG` | 加载 SVG 并转为 3D 形状 |
