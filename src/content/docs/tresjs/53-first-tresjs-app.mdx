## 什么是 TresJS

TresJS 是一个基于 Vue 3 的自定义渲染器（Custom Renderer），它让你能够以声明式的方式使用 Three.js。你在 Vue 模板中编写 3D 场景，就像写普通 HTML 一样自然。

### 为什么选择 TresJS

如果你熟悉原生 Three.js，你可能写过这样的命令式代码：

```ts
const scene = new THREE.Scene();
const mesh = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshStandardMaterial({ color: "mediumpurple" }),
);
scene.add(mesh);
```

用 TresJS，同样的事情只需在模板中声明：

```vue
<TresMesh>
  <TresBoxGeometry />
  <TresMeshStandardMaterial color="mediumpurple" />
</TresMesh>
```

:::tip
TresJS 的核心思想是：**你在写 Vue 模板，但渲染出的是 Three.js 对象**。所有 Three.js 的类都被自动映射为 `Tres` 前缀的 Vue 组件。
:::

## 项目搭建

### 安装依赖

```bash
npm install @tresjs/core @tresjs/cientos three
npm install -D @vitejs/plugin-vue @types/three
```

### 配置 Vite

TresJS 需要在 Vite 配置中注册模板编译器选项，告诉 Vue 将 `Tres` 前缀的标签视为自定义元素而非 HTML 元素：

```ts
// vite.config.ts
import { defineConfig } from "vite";
import vue from "@vitejs/plugin-vue";
import { templateCompilerOptions } from "@tresjs/core";

export default defineConfig({
  plugins: [
    vue({
      ...templateCompilerOptions,
    }),
  ],
});
```

:::caution
如果你省略了 `templateCompilerOptions`，Vue 会将 `<TresMesh>` 当作未知 HTML 标签，导致渲染失败。
:::

## TresCanvas

`TresCanvas` 是 TresJS 的入口组件，它创建 WebGL 渲染器和场景：

```vue
<TresCanvas
  clear-color="#333"
  :camera="{
    fov: 45,
    near: 0.1,
    far: 200,
    position: [3, 2, 6],
  }"
>
  <!-- 3D 内容 -->
</TresCanvas>
```

常用属性：

| 属性                    | 说明                                                                          |
| ----------------------- | ----------------------------------------------------------------------------- |
| `clear-color`           | 背景颜色                                                                      |
| `camera`                | 相机配置对象                                                                  |
| `shadows`               | 是否启用阴影                                                                  |
| `window-size`           | 让画布充满整个窗口                                                            |
| `render-mode`           | 渲染模式：`always`（每帧渲染）、`on-demand`（按需渲染）、`manual`（手动渲染） |
| `dpr`                   | 设备像素比，可传数字或 `[min, max]` 范围                                      |
| `tone-mapping`          | 色调映射，默认 `ACESFilmicToneMapping`                                        |
| `tone-mapping-exposure` | 色调映射曝光度                                                                |
| `fps-limit`             | 限制最大帧率                                                                  |

:::tip
使用 `render-mode="on-demand"` 可以在场景无变化时停止渲染，节省 GPU 资源。配合 `invalidate()` 方法可在需要时触发渲染。
:::

## 组件命名规则

Three.js 中的每个类都自动映射为 `Tres` 前缀的 Vue 组件：

| Three.js 类            | TresJS 组件                |
| ---------------------- | -------------------------- |
| `Mesh`                 | `TresMesh`                 |
| `BoxGeometry`          | `TresBoxGeometry`          |
| `MeshStandardMaterial` | `TresMeshStandardMaterial` |
| `DirectionalLight`     | `TresDirectionalLight`     |
| `PerspectiveCamera`    | `TresPerspectiveCamera`    |

属性使用 kebab-case（如 `position-x`、`rotation-y`），值通过 `:` 绑定传递。

### primitive 组件

`<primitive>` 用于将已有的 Three.js 对象实例插入场景：

```vue
<script setup>
import * as THREE from "three";

const geometry = new THREE.TorusGeometry(1, 0.4, 16, 32);
const material = new THREE.MeshStandardMaterial({ color: "orange" });
const mesh = new THREE.Mesh(geometry, material);
</script>

<template>
  <primitive :object="mesh" />
</template>
```

:::tip
`<primitive>` 在加载 GLTF 模型时特别常用：`<primitive :object="model.scene" />`。
:::

### extend 扩展

如果需要使用第三方 Three.js 类（不在 Three.js 核心中的），需要通过 `extend` 注册：

```vue
<script setup>
import { extend } from "@tresjs/core";
import { EffectComposer } from "three/examples/jsm/postprocessing/EffectComposer";

extend({ EffectComposer });
</script>

<template>
  <TresEffectComposer />
</template>
```

## useLoop

`useLoop` 是 TresJS 的动画钩子，用于在每一帧执行逻辑：

```vue
<script setup lang="ts">
import { useLoop } from "@tresjs/core";

const { onBeforeRender } = useLoop();

onBeforeRender(({ delta, elapsed }) => {
  // 每帧执行的逻辑
  mesh.value.rotation.y += delta;
});
</script>
```

回调函数接收的上下文参数：

| 参数         | 说明                                                |
| ------------ | --------------------------------------------------- |
| `delta`      | 上一帧到当前帧的时间间隔（秒）                      |
| `elapsed`    | 从启动到现在的总时间（秒）                          |
| `scene`      | 当前场景引用                                        |
| `renderer`   | WebGL 渲染器实例                                    |
| `camera`     | 当前相机引用                                        |
| `invalidate` | 触发按需渲染（配合 `render-mode="on-demand"` 使用） |

`useLoop` 还提供控制方法：

```ts
const { onBeforeRender, start, stop, isActive } = useLoop();

// 暂停/恢复动画循环
stop();
start();
```

### 优先级

`onBeforeRender` 支持第二个参数设置优先级（数字越小越先执行）：

```ts
onBeforeRender(({ delta }) => {
  // 先更新物理
}, 0);

onBeforeRender(({ delta }) => {
  // 后更新动画
}, 1);
```

## useTres

`useTres` 用于获取场景上下文，访问相机、渲染器等核心对象：

```vue
<script setup>
import { useTres } from "@tresjs/core";

const { camera, renderer, scene, sizes } = useTres();
</script>
```

| 属性       | 说明                                       |
| ---------- | ------------------------------------------ |
| `scene`    | Three.js 场景对象                          |
| `renderer` | WebGL 渲染器实例                           |
| `camera`   | 当前激活的相机                             |
| `sizes`    | 画布尺寸信息（width、height、aspectRatio） |
| `controls` | 当前控制器实例                             |

## 内置指令

TresJS 提供了几个实用的内置指令：

```vue
<!-- 在控制台打印对象信息 -->
<TresMesh v-log />

<!-- 显示光源辅助线 -->
<TresDirectionalLight v-light-helper />

<!-- 显示两个对象之间的距离箭头 -->
<TresMesh v-distance-to="targetRef" />
```

## 常用 API 速查

| API                                 | 说明                                      |
| ----------------------------------- | ----------------------------------------- |
| `<TresCanvas>`                      | 入口组件，创建 WebGL 渲染器和场景         |
| `useLoop().onBeforeRender()`        | 动画钩子，每帧执行                        |
| `useTres()`                         | 获取场景上下文（相机、渲染器等）          |
| `<TresMesh>`, `<TresBoxGeometry>`   | 组件命名规则：Three.js 类名加 `Tres` 前缀 |
| `<primitive :object="obj" />`       | 插入已有的 Three.js 对象实例              |
| `extend({ ClassName })`             | 注册第三方 Three.js 类                    |
| `ref="name"` + `const name = ref()` | 模板引用，获取 Three.js 对象实例          |
| `@click="fn"`                       | 事件绑定，使用 Vue 的 `@` 语法            |
