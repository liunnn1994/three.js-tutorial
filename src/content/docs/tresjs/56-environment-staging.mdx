## 环境光照

真实感渲染的关键在于环境光照。TresJS 通过 `@tresjs/cientos` 提供了便捷的环境贴图组件。

### Environment 组件

`Environment` 组件可以加载 HDR 环境贴图，为场景提供逼真的光照和反射：

```vue
<script setup>
import { Environment } from '@tresjs/cientos'
</script>

<template>
  <TresCanvas shadows>
    <Environment preset="sunset" background />
    <!-- ... -->
  </TresCanvas>
</template>
```

常用属性：

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `preset` | 预设环境名称 | — |
| `background` | 设为场景背景 | `false` |
| `blur` | 背景模糊程度 | `0` |
| `environment-intensity` | 环境光强度 | — |
| `background-intensity` | 背景亮度 | — |
| `resolution` | 立方体贴图分辨率 | — |

内置预设：

| 预设名 | 说明 |
|--------|------|
| `sunset` | 日落 |
| `dawn` | 黎明 |
| `night` | 夜晚 |
| `warehouse` | 仓库 |
| `forest` | 森林 |
| `apartment` | 公寓 |
| `studio` | 摄影棚 |
| `city` | 城市 |
| `park` | 公园 |
| `lobby` | 大堂 |

### envMapIntensity

标准材质的 `env-map-intensity` 属性控制环境反射的强度：

```vue
<TresMeshStandardMaterial color="orange" :env-map-intensity="3.5" />
```

值越大，反射越强烈。通常 1-5 之间的值看起来比较自然。

## 接触阴影

### ContactShadows

`ContactShadows` 提供柔和的接触阴影效果，比 Three.js 原生阴影性能更好：

```vue
<ContactShadows
  :position="[0, 0, 0]"
  :scale="10"
  :resolution="512"
  :far="5"
  color="#4b2709"
  :opacity="0.5"
  :blur="2.8"
/>
```

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `opacity` | 阴影透明度 | `1` |
| `blur` | 模糊程度 | `1` |
| `color` | 阴影颜色 | `#000000` |
| `scale` | 阴影平面缩放 | `10` |
| `resolution` | 渲染分辨率 | `512` |
| `smooth` | 平滑阴影 | `true` |
| `far` | 最大检测距离 | — |

## 天空

### Sky

基于大气散射模型的天空渲染组件：

```vue
<script setup>
import { Sky } from '@tresjs/cientos'
</script>

<template>
  <Sky :elevation="30" :azimuth="180" :turbidity="3.4" :rayleigh="3" />
</template>
```

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `turbidity` | 大气浑浊度 | `3.4` |
| `rayleigh` | 瑞利散射系数 | `3` |
| `elevation` | 太阳仰角（度） | `0.6` |
| `azimuth` | 太阳方位角（度） | `180` |
| `distance` | 天空距离 | `450000` |

## 粒子效果

### Stars

在场景中添加星空效果：

```vue
<script setup>
import { Stars } from '@tresjs/cientos'
</script>

<template>
  <Stars :count="5000" :depth="50" :radius="100" :size="0.1" />
</template>
```

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `count` | 星星数量 | `5000` |
| `depth` | 星空深度 | `50` |
| `radius` | 星空半径 | `100` |
| `size` | 星星大小 | `0.1` |
| `size-attenuation` | 近大远小 | `true` |

### Sparkles

闪烁粒子效果，可以让物体表面产生光点：

```vue
<script setup>
import { Sparkles } from '@tresjs/cientos'
</script>

<template>
  <TresMesh>
    <TresBoxGeometry />
    <TresMeshStandardMaterial color="darkblue" />
  </TresMesh>
  <Sparkles :size="3" :scale="[4, 4, 4]" :speed="0.4" :count="50" color="gold" />
</template>
```

## 快速布景

### Stage

`Stage` 组件一键设置完整的场景布景，包含环境光照、地面和阴影：

```vue
<script setup>
import { Stage } from '@tresjs/cientos'
</script>

<template>
  <TresCanvas>
    <Stage environment="city" :intensity="0.5">
      <TresMesh>
        <TresBoxGeometry />
        <TresMeshStandardMaterial color="mediumpurple" />
      </TresMesh>
    </Stage>
  </TresCanvas>
</template>
```

:::tip
`Stage` 非常适合产品展示页面，一行代码即可获得专业级的光照和环境。
:::
