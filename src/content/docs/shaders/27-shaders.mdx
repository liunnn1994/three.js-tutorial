## 什么是着色器

前面课程中我们使用的所有材质（MeshStandardMaterial、MeshBasicMaterial 等）内部都在使用**着色器**。着色器是运行在 **GPU**（显卡）上的小程序，用 **GLSL**（OpenGL Shading Language）编写。

学习着色器意味着你不再受限于 Three.js 内置的材质效果，可以创造出任何你能想象的视觉效果。

### 渲染管线

当你渲染一帧画面时，数据经过以下步骤：

```
JavaScript 代码
    ↓ (通过 uniform 和 attribute 传递数据)
顶点着色器  ← 处理每个顶点的位置（运行 N 次，N = 顶点数量）
    ↓ (通过 varying 传递数据到片元着色器)
片元着色器  ← 处理每个像素的颜色（运行 M 次，M = 像素数量）
    ↓
屏幕上的像素
```

- **顶点着色器**：决定每个顶点在屏幕上的位置。输入是一个顶点的 3D 坐标，输出是它在屏幕上的 2D 坐标。
- **片元着色器**：决定每个像素的颜色。输入是插值后的数据，输出是一个 RGBA 颜色值。

### GPU vs CPU

为什么用 GPU？因为 GPU 有数千个核心，可以**同时**处理大量顶点和像素。一个拥有 200 万个三角面的模型，GPU 可以在瞬间完成所有顶点和像素的计算。

## ShaderMaterial

Three.js 提供了 `ShaderMaterial` 让你编写自定义着色器：

```js
import testVertexShader from "./shaders/test/vertex.glsl";
import testFragmentShader from "./shaders/test/fragment.glsl";

const material = new THREE.ShaderMaterial({
  vertexShader: testVertexShader,
  fragmentShader: testFragmentShader,
  uniforms: {
    uTime: { value: 0 },
    uColor: { value: new THREE.Color("orange") },
  },
});
```

### 为什么用单独的 .glsl 文件

将着色器代码放在独立的 `.glsl` 文件中，比写在 JS 字符串中更好：

- 语法高亮（VS Code 安装 "Shader languages support" 扩展）
- 代码可读性
- 便于维护

Vite 原生支持导入 `.glsl` 文件作为字符串。

## RawShaderMaterial

到目前为止，我们一直在用 `ShaderMaterial`。你可能注意到了一个奇怪的现象 —— 我们在 GLSL 代码中使用了 `position`、`uv`、`projectionMatrix` 等变量，但从来没有声明过它们。这些是 Three.js **自动注入**到着色器中的内置变量。

但有时你需要**完全控制**着色器代码 —— 比如你从 Shadertoy 复制了一段着色器代码，或者你想精确知道着色器的每一行在做什么。这就是 `RawShaderMaterial` 的用途。

`RawShaderMaterial` **不会**自动注入任何变量。你必须手动声明所有 uniform 和 attribute，包括 GLSL 的 `precision` 语句（指定浮点数精度）：

```js
const material = new THREE.RawShaderMaterial({
  vertexShader: `
    precision highp float; // 必须手动声明精度

    // 必须手动声明所有 attribute
    attribute vec3 position;

    // 必须手动声明所有 uniform
    uniform mat4 projectionMatrix;
    uniform mat4 modelViewMatrix;

    void main() {
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    precision highp float;

    void main() {
      gl_FragColor = vec4(1.0, 0.0, 0.0, 1.0);
    }
  `,
});
```

### ShaderMaterial vs RawShaderMaterial

| 特性                        | ShaderMaterial | RawShaderMaterial                    |
| --------------------------- | -------------- | ------------------------------------ |
| 自动提供 position/uv/normal | 是             | 否                                   |
| 自动提供矩阵 uniform        | 是             | 否                                   |
| 自动添加 precision          | 是             | 否                                   |
| 适合场景                    | 大多数情况     | 移植非 Three.js 着色器、需要完全控制 |

:::tip[何时使用 RawShaderMaterial？]
大多数情况下使用 `ShaderMaterial` 即可。`RawShaderMaterial` 主要用于：

- 从 Shadertoy 等平台移植着色器（这些着色器不依赖 Three.js 的变量命名）
- 需要精确控制着色器的每一行代码
- 性能优化（避免不必要的内置变量）
  :::

## Uniforms（统一变量）

Uniform 是从 JavaScript 传递到着色器的**全局变量**，所有顶点和片元共享同一个值。

### 命名约定

自定义 uniform 以 `u` 前缀开头（如 `uTime`、`uColor`），这是 Three.js 社区的约定，帮助你区分自定义变量和 Three.js 内置变量。

### 支持的数据类型

```js
uniforms: {
    uFloat:   { value: 1.0 },                          // float
    uInt:     { value: 1 },                              // int
    uVector2: { value: new THREE.Vector2(10, 5) },      // vec2
    uVector3: { value: new THREE.Vector3(1, 0, 0) },    // vec3
    uColor:   { value: new THREE.Color('orange') },      // vec3 (颜色)
    uTexture: { value: flagTexture },                    // sampler2D
}
```

### 在动画循环中更新

```js
const tick = () => {
  timer.update();
  const elapsedTime = timer.getElapsed();
  material.uniforms.uTime.value = elapsedTime;
  // ...
};
```

## Attributes（属性）

Attribute 是**每个顶点**的数据。Three.js 内置了三个 attribute：

| 名称       | 类型 | 说明                 |
| ---------- | ---- | -------------------- |
| `position` | vec3 | 顶点的 3D 坐标       |
| `uv`       | vec2 | 纹理坐标（0-1 范围） |
| `normal`   | vec3 | 顶点法线方向         |

### 自定义 Attribute

以 `a` 前缀命名（如 `aRandom`、`aScale`）：

```js
// JavaScript 端 — 创建自定义 attribute
const count = geometry.attributes.position.count;
const randoms = new Float32Array(count);
for (let i = 0; i < count; i++) {
  randoms[i] = Math.random();
}
geometry.setAttribute("aRandom", new THREE.BufferAttribute(randoms, 1));
```

```glsl
// GLSL 端 — 声明 attribute
attribute float aRandom;
```

:::caution
不要重用 Three.js 内置的 attribute 名称（`color`、`uv`、`normal`）。如果需要自定义的顶点颜色，用 `aColor` 而不是 `color`。
:::

## Varyings（变量传递）

Varying 用于从顶点着色器向片元着色器传递数据。GPU 会自动在顶点之间**插值** varying 的值。

```glsl
// 顶点着色器
varying float vElevation;
varying vec2 vUv;

void main() {
    vElevation = elevation;   // 设置值
    vUv = uv;
}

// 片元着色器（同名声明，自动接收插值后的值）
varying float vElevation;
varying vec2 vUv;

void main() {
    // vElevation 已被 GPU 插值
    gl_FragColor = vec4(vElevation, 0.0, 0.0, 1.0);
}
```

以 `v` 前缀命名 varying 变量（如 `vUv`、`vElevation`）。

## 顶点着色器详解

```glsl
uniform float uTime;
uniform vec2 uFrequency;

// Three.js 自动提供的矩阵
// modelMatrix      — 模型变换矩阵
// viewMatrix       — 视图变换矩阵
// projectionMatrix — 投影矩阵

void main() {
    // 1. 将顶点从模型空间变换到世界空间
    vec4 modelPosition = modelMatrix * vec4(position, 1.0);

    // 2. 修改顶点位置（如波浪效果）
    float elevation = sin(modelPosition.x * uFrequency.x + uTime) * 0.1;
    modelPosition.z += elevation;

    // 3. 变换到视图空间
    vec4 viewPosition = viewMatrix * modelPosition;

    // 4. 投影到屏幕空间
    vec4 projectedPosition = projectionMatrix * viewPosition;

    // 5. 设置最终位置
    gl_Position = projectedPosition;
}
```

也可以简化为：

```glsl
void main() {
    vec4 modelPosition = modelMatrix * vec4(position, 1.0);
    modelPosition.z += sin(modelPosition.x * uFrequency.x + uTime) * 0.1;

    gl_Position = projectionMatrix * viewMatrix * modelPosition;
}
```

## 片元着色器详解

```glsl
uniform float uTime;
uniform vec3 uColor;
uniform sampler2D uTexture;

varying vec2 vUv;

void main() {
    // 采样纹理颜色
    vec4 textureColor = texture2D(uTexture, vUv);

    // 输出最终颜色 (RGBA)
    gl_FragColor = textureColor;
}
```

`gl_FragColor` 是片元着色器的输出变量，表示这个像素的最终颜色。`vec4(r, g, b, a)` 中每个分量范围 0.0-1.0。

## GLSL 数据类型速查

| 类型        | 说明       | 示例                       |
| ----------- | ---------- | -------------------------- |
| `float`     | 浮点数     | `1.0`, `0.5`, `3.14`       |
| `int`       | 整数       | `1`, `42`                  |
| `bool`      | 布尔值     | `true`, `false`            |
| `vec2`      | 二维向量   | `vec2(1.0, 0.5)`           |
| `vec3`      | 三维向量   | `vec3(1.0, 0.0, 0.5)`      |
| `vec4`      | 四维向量   | `vec4(1.0, 0.0, 0.5, 1.0)` |
| `mat2/3/4`  | 矩阵       | `mat4(1.0)`                |
| `sampler2D` | 纹理采样器 | `texture2D(sampler, uv)`   |

### 向量操作

```glsl
vec3 color = vec3(1.0, 0.5, 0.0);

// 访问分量（xyzw 或 rgba 或 stpq）
float r = color.r;    // 1.0
float x = color.x;    // 1.0 (等价)

// 向量数学
vec3 a = vec3(1.0, 2.0, 3.0);
vec3 b = vec3(0.5, 0.5, 0.5);
vec3 sum = a + b;           // 逐分量相加
vec3 scaled = a * 2.0;      // 逐分量缩放
```

:::tip
GLSL 中 `1` 是整数，`1.0` 是浮点数。大部分 GLSL 函数要求浮点参数。写 `1` 而不是 `1.0` 会导致编译错误。
:::

## GLSL 内置函数参考

GLSL 提供了丰富的内置函数。以下是着色器编程中最常用的函数，按类别整理。

### 数学函数

| 函数                           | 说明                             |
| ------------------------------ | -------------------------------- |
| `abs(x)`                       | 绝对值                           |
| `sign(x)`                      | 符号（-1、0、1）                 |
| `floor(x)` / `ceil(x)`         | 向下/向上取整                    |
| `fract(x)`                     | 取小数部分（`x - floor(x)`）     |
| `mod(x, y)`                    | 取模                             |
| `min(x, y)` / `max(x, y)`      | 最小值/最大值                    |
| `clamp(x, min, max)`           | 将值限制在范围内                 |
| `mix(a, b, t)`                 | 线性插值：`a * (1-t) + b * t`    |
| `step(edge, x)`                | 阶梯函数：`x < edge ? 0.0 : 1.0` |
| `smoothstep(edge0, edge1, x)`  | 平滑阶梯函数（Hermite 插值）     |
| `sin(x)` / `cos(x)` / `tan(x)` | 三角函数                         |
| `pow(x, y)`                    | 幂运算（x 的 y 次方）            |
| `exp(x)` / `log(x)`            | 指数/对数                        |
| `sqrt(x)`                      | 平方根                           |

### 向量函数

| 函数                 | 说明                               |
| -------------------- | ---------------------------------- |
| `length(v)`          | 向量长度                           |
| `distance(p0, p1)`   | 两点间距离                         |
| `dot(x, y)`          | 点积（判断两个方向的重合程度）     |
| `cross(x, y)`        | 叉积（得到垂直于两向量的向量）     |
| `normalize(v)`       | 归一化为单位向量（长度为 1）       |
| `reflect(I, N)`      | 反射向量（I 为入射方向，N 为法线） |
| `refract(I, N, eta)` | 折射向量（eta 为折射率比值）       |

### 纹理函数

| 函数                          | 说明                       |
| ----------------------------- | -------------------------- |
| `texture2D(sampler, coord)`   | 采样 2D 纹理               |
| `textureCube(sampler, coord)` | 采样立方体纹理（环境贴图） |

:::tip[常用函数组合技巧]

- **平滑过渡**：`smoothstep(0.0, 1.0, value)` — 比 `step` 更柔和的开关
- **限定范围**：`clamp(value, 0.0, 1.0)` — 确保值不会超出 0~1
- **混合两种颜色**：`mix(colorA, colorB, factor)` — factor=0 为 A，factor=1 为 B
- **判断朝向**：`dot(normal, lightDir)` — 正值=面向光，负值=背向光
- **避免 if/else**：用 `step` 和 `mix` 替代条件判断（GPU 对分支语句效率较低）
  :::

## 调试着色器

着色器在 GPU 上运行，无法用 `console.log` 调试。常用技巧：

1. **用颜色可视化值** — 将数值映射到颜色通道

   ```glsl
   gl_FragColor = vec4(vec3(someValue), 1.0);
   ```

2. **检查编译错误** — 查看浏览器控制台中的 WebGL 错误信息

3. **从简单开始** — 先确保能渲染纯色，再逐步添加效果

4. **使用 ShaderMaterial 的 `wireframe: true`** — 查看顶点布局

## 扩展内置材质（onBeforeCompile）

### 为什么需要这个？

学了 ShaderMaterial 之后，你可能会想："如果我只想在 MeshStandardMaterial 的基础上做一个小改动（比如让顶点轻微抖动），难道要重写整个着色器吗？" 答案是：不需要。`onBeforeCompile` 允许你**在内置材质的着色器被编译之前修改它的源代码**。

**生活中的类比：** 就像你买了一个装修好的房子（内置材质），不需要推倒重建 —— 你只需要在某个房间里换一面墙的颜色（注入自定义代码）。

```js
const material = new THREE.MeshStandardMaterial({ color: 0x00ff00 });

material.onBeforeCompile = (shader) => {
  // 添加自定义 uniform
  shader.uniforms.time = { value: 0 };

  // 保存引用，以便在动画循环中更新
  material.userData.shader = shader;

  // 在顶点着色器的 "begin_vertex" 位置注入代码
  shader.vertexShader = shader.vertexShader.replace(
    "#include <begin_vertex>",
    `
    #include <begin_vertex>
    transformed.y += sin(position.x * 10.0 + time) * 0.1;
    `,
  );

  // 在顶部添加 uniform 声明
  shader.vertexShader = "uniform float time;\n" + shader.vertexShader;
};

// 在动画循环中更新 uniform
const tick = () => {
  if (material.userData.shader) {
    material.userData.shader.uniforms.time.value = clock.getElapsedTime();
  }
};
```

### 常用注入点

Three.js 的着色器由可复用的代码片段（chunk）组成。你可以用 `replace` 替换这些 chunk 来注入自定义代码：

**顶点着色器：**

| Chunk                           | 位置                     |
| ------------------------------- | ------------------------ |
| `#include <begin_vertex>`       | 顶点位置计算完成后       |
| `#include <project_vertex>`     | `gl_Position` 计算完成后 |
| `#include <beginnormal_vertex>` | 法线计算开始处           |

**片元着色器：**

| Chunk                        | 位置                 |
| ---------------------------- | -------------------- |
| `#include <color_fragment>`  | 漫反射颜色计算完成后 |
| `#include <output_fragment>` | 最终输出前           |
| `#include <fog_fragment>`    | 雾效应用后           |

:::tip
`onBeforeCompile` 是在不重写整个着色器的情况下自定义内置材质的强大方式。它保留了 PBR 光照、阴影等所有内置功能，同时允许你添加自定义的顶点变形或颜色效果。后续课程（Lesson 31 - 修改材质）会更深入地使用这个技术。
:::

:::caution
使用 `onBeforeCompile` 时，材质不能直接 `clone()`。如果需要克隆，需要重新设置 `onBeforeCompile` 回调。
:::

## ShaderChunk（着色器代码片段）

Three.js 内部的着色器由许多可复用的代码片段（chunk）组成。你可以在自己的着色器中使用这些 chunk：

```js
import { ShaderChunk } from "three";

const fragmentShader = `
  ${ShaderChunk.common}
  ${ShaderChunk.packing}

  // 现在可以使用 common 和 packing 中定义的函数
  uniform sampler2D depthTexture;
  varying vec2 vUv;

  void main() {
    float depth = texture2D(depthTexture, vUv).r;
    // perspectiveDepthToViewZ 来自 packing chunk
    float linearDepth = perspectiveDepthToViewZ(depth, 0.1, 1000.0);
    gl_FragColor = vec4(vec3(linearDepth), 1.0);
  }
`;
```

常用的 chunk 包括：`common`（常用常量和函数）、`packing`（深度编解码）、`fog_pars_fragment`（雾效参数）、`lights_pars_begin`（光照参数）等。

:::note
ShaderChunk 是 Three.js 的内部机制，API 可能会随版本变化。在大多数情况下，你不需要直接使用它，除非你在编写需要与 Three.js 内部系统深度集成的自定义着色器。
:::
