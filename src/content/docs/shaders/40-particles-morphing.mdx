## 粒子变形简介

在本课中，我们将创建一个粒子变形动画 — 粒子群从一个形状（如球体）平滑过渡到另一个形状（如苏珊娜猴头、立方体或文字），最终呈现完整的文字图案。这种效果在网页设计、数据可视化和创意编码中非常流行，能够产生极具视觉冲击力的过渡动画。

## 为什么必须使用着色器

你可能会想：能否通过 JavaScript 在每一帧中更新粒子的位置属性来实现变形？

答案是：**技术上可行，但性能极差**。原因如下：

1. **CPU 瓶颈** — 假设有 10,000 个粒子，每帧都需要在 CPU 上计算每个粒子从当前位置到目标位置的插值，这对 CPU 来说是沉重的负担。
2. **GPU 数据传输** — 更新后的属性数据还需要从 CPU 传输到 GPU（即更新 BufferAttribute），这个传输过程本身就是性能瓶颈。
3. **逐帧重复** — 上述两个步骤需要在**每一帧**都执行一次，且以 60fps 运行时，意味着每秒要进行 60 次完整的计算和数据传输。

相比之下，使用着色器的方式：
- 只需将初始位置和目标位置**一次性**发送给 GPU
- 通过一个 `progress` uniform 控制插值进度
- 所有粒子的插值计算在 GPU 上**并行执行**，几乎没有性能开销

:::caution
还有一种 GPGPU（General-Purpose computing on GPU）技术也可以实现类似效果，甚至更加强大。GPGPU 允许在 GPU 上执行通用计算，不仅仅是图形渲染。不过对于我们的当前知识水平来说，GPGPU 过于复杂，将在后续课程中专门学习。本课着色器方案完全可以胜任粒子的变形动画需求。
:::

## 核心原理

着色器变形的核心思想非常简洁：

1. **发送两组位置数据** — 初始形状的位置（`position` 属性）和目标形状的位置（`positionTarget` 自定义属性）。
2. **一个 progress uniform** — 范围从 0 到 1 的浮点数，控制两个形状之间的混合程度。
3. **在顶点着色器中使用 `mix()` 函数** — 根据进度在两个位置之间线性插值。
4. **用 GSAP 动画 progress** — 点击按钮时，通过 GSAP 将 progress 从 0 动画到 1。

```
progress = 0  -->  完全显示初始形状
progress = 0.5  -->  两个形状的中间状态
progress = 1  -->  完全显示目标形状
```

## 项目设置

场景中有一个可调节的背景色，默认为深色。静态 `models/` 文件夹中准备了多个 GLB 格式的 3D 模型（球体、苏珊娜、文字等），这些就是粒子变形的目标形状。GLTFLoader 已经配置好，并集成了 DracoLoader 用于解码压缩的 GLB 文件。

着色器文件位于 `src/shaders/particles/` 文件夹中，包含顶点着色器和片元着色器。项目中已经导入了 GSAP，用于动画化 progress uniform。

粒子数量大约为 10,000 个，但这个数字可以轻松增加到 100,000 甚至更多而不会显著影响性能，因为所有计算都在 GPU 上进行。

## 准备多形状数据

我们需要为每个粒子准备多个形状对应的目标位置。由于所有粒子数量相同，每个形状都需要精确相同数量的位置坐标：

```js
const count = 10000
const positions = new Float32Array(count * 3)     // 初始/当前形状的顶点位置
const targetPositions = new Float32Array(count * 3)  // 目标形状的顶点位置
const scales = new Float32Array(count)             // 每个粒子的随机缩放
const randoms = new Float32Array(count)            // 每个粒子的随机参数
```

对于内置的几何形状（如球体、环面），可以在 JavaScript 中程序化生成顶点位置：

```js
// 生成球体上的随机点
for (let i = 0; i < count; i++) {
    const theta = Math.random() * Math.PI * 2  // 经度 [0, 2PI]
    const phi = Math.acos(2 * Math.random() - 1)  // 纬度 [0, PI]
    const r = Math.random() * 1.5  // 随机半径

    positions[i * 3]     = r * Math.sin(phi) * Math.cos(theta)
    positions[i * 3 + 1] = r * Math.sin(phi) * Math.sin(theta)
    positions[i * 3 + 2] = r * Math.cos(phi)
}
```

对于外部模型（如苏珊娜、文字），则通过 GLTFLoader 加载后从几何体中提取顶点位置。关键是要确保**每个形状的粒子数量相同**，如果模型的顶点数不够，可以随机重复采样现有顶点；如果顶点数过多，可以随机选取子集。

## 顶点着色器 — 基础变形

```glsl
uniform float uTime;
uniform float uMorphProgress;    // 变形进度 [0, 1]
uniform float uSize;
uniform float uResolution;
attribute vec3 position;         // 初始形状位置（Three.js 内置）
attribute vec3 positionTarget;   // 目标形状位置（自定义属性）
attribute float aScale;
attribute float aRandom;
varying float vMorph;

void main() {
    // 核心变形逻辑 — 在两个形状之间线性插值
    vec3 morphed = mix(position, positionTarget, uMorphProgress);

    // 添加过渡噪声 — 让变形过程更有机
    float noise = sin(morphed.x * 5.0 + uTime) * sin(morphed.y * 5.0 + uTime) * 0.1;
    // 噪声在过渡中间最强，在起点和终点消失
    noise *= (1.0 - abs(uMorphProgress * 2.0 - 1.0));
    morphed += noise;

    vec4 modelPosition = modelMatrix * vec4(morphed, 1.0);
    vec4 viewPosition = viewMatrix * modelPosition;
    gl_Position = projectionMatrix * viewPosition;

    // 粒子大小
    gl_PointSize = uSize * aScale * uResolution.y * (1.0 / -viewPosition.z);

    vMorph = uMorphProgress;
}
```

### `mix()` 函数详解

GLSL 的 `mix(a, b, t)` 函数执行线性插值：`a * (1.0 - t) + b * t`。

- 当 `uMorphProgress = 0` 时，`morphed = position`（完全显示初始形状）
- 当 `uMorphProgress = 0.5` 时，`morphed` 是两个形状的中间位置
- 当 `uMorphProgress = 1` 时，`morphed = positionTarget`（完全显示目标形状）

### 过渡噪声

直接使用 `mix()` 的线性插值效果虽然正确，但看起来过于"机械" — 粒子沿着直线从 A 飞到 B，缺乏动感。添加噪声可以打破这种规律性：

```glsl
float noise = sin(morphed.x * 5.0 + uTime) * sin(morphed.y * 5.0 + uTime) * 0.1;
noise *= (1.0 - abs(uMorphProgress * 2.0 - 1.0));
```

噪声强度乘以 `(1.0 - abs(uMorphProgress * 2.0 - 1.0))`，这个表达式在 `uMorphProgress = 0` 和 `uMorphProgress = 1` 时为 0，在 `uMorphProgress = 0.5` 时为 1，形成一个钟形曲线。这意味着噪声只在变形的**中间阶段**最强烈，在起始和结束状态完全消失，不会干扰最终形状的清晰度。

## 形状切换动画

使用 GSAP 来动画化 `uMorphProgress`，并在动画完成后更新属性数据：

```js
const shapes = [targetA, targetB, targetC]
let currentShapeIndex = 0
let nextShapeIndex = 1

function morphTo(targetIndex) {
    nextShapeIndex = targetIndex

    // GSAP 动画 progress 从 0 到 1
    gsap.to(material.uniforms.uMorphProgress, {
        value: 1,
        duration: 2,
        ease: 'power2.inOut',
        onComplete: () => {
            // 动画完成后：将目标形状变为新的初始形状
            currentShapeIndex = nextShapeIndex

            // 更新 position 属性为当前目标形状
            const geometry = particles.geometry
            geometry.attributes.position.array.set(shapes[currentShapeIndex])
            geometry.attributes.position.needsUpdate = true

            // 重置 progress
            material.uniforms.uMorphProgress.value = 0

            // 更新 positionTarget 为下一个目标形状
            geometry.attributes.positionTarget.array.set(shapes[nextShapeIndex])
            geometry.attributes.positionTarget.needsUpdate = true
        }
    })
}
```

这个动画流程的关键是：当一次变形完成后，将目标形状"固化"为新的初始形状（更新 position 属性），重置 progress 为 0，然后设置新的目标形状。这样，每次点击按钮时，变形总是从当前形状出发。

:::tip
`ease: 'power2.inOut'` 缓动函数让变形在开始和结束时缓慢，中间加速，产生更自然的运动感。你也可以尝试 `elastic.out`（弹性效果）或 `back.inOut`（过冲效果）来增加不同的运动风格。
:::

## 多形状切换 — 连续变形

当有多个形状（如球体、苏珊娜、立方体、文字）时，可以将它们组织成一个数组并实现循环切换：

```js
// UI 按钮
const buttons = document.querySelectorAll('.morph-button')
buttons.forEach((button, index) => {
    button.addEventListener('click', () => {
        if (index !== currentShapeIndex) {
            morphTo(index)
        }
    })
})
```

也可以添加一个自动播放模式，让粒子在不同形状之间不断循环变形，形成一个引人注目的展示动画。

## 过渡效果增强

### 粒子扩散效果

在变形过程中让粒子向外扩散，使过渡更加戏剧化：

```glsl
// 过渡期间粒子沿随机方向扩散
float transitionEffect = sin(uMorphProgress * 3.14159) * 0.5;
morphed += normalize(aRandomness) * transitionEffect;
```

`sin(uMorphProgress * PI)` 在 progress 为 0 和 1 时为 0，在 0.5 时为 1（最大扩散），与噪声的强度曲线一致。`aRandomness` 是每个粒子的随机方向向量，让扩散方向各不相同，避免所有粒子沿同一方向移动。

### 旋转效果

在变形过程中加入旋转可以让过渡更加动感：

```glsl
// 过渡期间粒子绕 Y 轴旋转
float angle = uMorphProgress * 3.14159 * 2.0;  // 旋转一整圈
mat2 rotation = mat2(cos(angle), -sin(angle), sin(angle), cos(angle));
// 在过渡期间部分应用旋转
morphed.xy = rotation * morphed.xy * (0.5 + transitionEffect * 0.5);
```

这里 `(0.5 + transitionEffect * 0.5)` 控制旋转的混合程度 — 在过渡中间旋转最强（值为 1，完全旋转），在起始和结束状态旋转减半（值为 0.5），保持一定的旋转余量使过渡更加平滑。

### 粒子大小变化

让粒子在过渡过程中大小发生变化也能增强视觉冲击力：

```glsl
// 过渡期间粒子略微变大
float sizeMultiplier = 1.0 + transitionEffect * 0.5;
gl_PointSize = uSize * aScale * sizeMultiplier * uResolution.y * (1.0 / -viewPosition.z);
```

## 片元着色器 — 发光粒子

变形效果中的粒子应该有一种发光的外观 — 中心是完美的白色，然后快速衰减并消失：

```glsl
varying float vMorph;

void main() {
    // 到粒子中心的距离
    float dist = length(gl_PointCoord - vec2(0.5));

    // 丢弃圆形外的片段
    if (dist > 0.5) discard;

    // 从中心到边缘快速衰减的亮度
    float strength = 1.0 - dist * 2.0;
    strength = pow(strength, 1.5);  // 非线性衰减

    // 颜色 — 过渡期间带有色调变化
    vec3 baseColor = mix(
        vec3(0.2, 0.5, 1.0),   // 起始颜色（蓝色）
        vec3(1.0, 0.3, 0.5),   // 目标颜色（粉色）
        vMorph                    // 根据变形进度混合
    );

    gl_FragColor = vec4(baseColor * strength, strength);
}
```

`pow(strength, 1.5)` 使亮度衰减曲线更加陡峭，粒子的发光区域更加集中在中心，而边缘的过渡更加锐利。这创造了类似星光的视觉效果，每个粒子看起来像一个小小的发光点。

## 模型加载与顶点采样

当从 GLB 模型加载形状数据时，需要处理一个重要问题：**模型的顶点数量可能与我们预设的粒子数量不一致**。

解决方案是使用**随机采样**策略：

```js
function sampleGeometry(geometry, targetCount) {
    const sourcePositions = geometry.attributes.position.array
    const sourceCount = sourcePositions.length / 3
    const targetPositions = new Float32Array(targetCount * 3)

    for (let i = 0; i < targetCount; i++) {
        // 从源几何体中随机选取一个顶点
        const sourceIndex = Math.floor(Math.random() * sourceCount) * 3
        targetPositions[i * 3]     = sourcePositions[sourceIndex]
        targetPositions[i * 3 + 1] = sourcePositions[sourceIndex + 1]
        targetPositions[i * 3 + 2] = sourcePositions[sourceIndex + 2]
    }

    return targetPositions
}
```

如果模型的表面分布不均匀（如文字模型的正面有很多顶点，但侧面和背面很少），可以在采样时添加少量随机偏移来增加粒子的"体积感"，而不是所有粒子都紧贴在模型的表面。

## 形状居中与缩放

不同模型的大小和位置可能差异很大。为了保证变形时形状之间的过渡合理，需要对所有形状进行**归一化处理**：

```js
function normalizePositions(positions) {
    // 找到边界框
    let minX = Infinity, maxX = -Infinity
    let minY = Infinity, maxY = -Infinity
    let minZ = Infinity, maxZ = -Infinity

    for (let i = 0; i < positions.length; i += 3) {
        minX = Math.min(minX, positions[i])
        maxX = Math.max(maxX, positions[i])
        minY = Math.min(minY, positions[i + 1])
        maxY = Math.max(maxY, positions[i + 1])
        minZ = Math.min(minZ, positions[i + 2])
        maxZ = Math.max(maxZ, positions[i + 2])
    }

    // 计算中心和缩放因子
    const centerX = (minX + maxX) / 2
    const centerY = (minY + maxY) / 2
    const centerZ = (minZ + maxZ) / 2
    const maxDim = Math.max(maxX - minX, maxY - minY, maxZ - minZ)
    const scale = 2.0 / maxDim  // 归一化到 [-1, 1] 范围

    // 应用变换
    for (let i = 0; i < positions.length; i += 3) {
        positions[i]     = (positions[i] - centerX) * scale
        positions[i + 1] = (positions[i + 1] - centerY) * scale
        positions[i + 2] = (positions[i + 2] - centerZ) * scale
    }

    return positions
}
```

归一化确保所有形状大致在相同的空间范围内，使变形过渡时粒子不需要移动过远的距离，效果更加自然。

:::tip
变形过渡的关键是 `mix()` 函数和中间状态的噪声扰动。使用 `sin(progress * PI)` 让过渡在中间时刻效果最强，而在起始和结束时保持稳定。这种"中间膨胀、两端收敛"的节奏感是优秀变形动画的核心特征。
:::
