## 从前端数据流理解 GPU 输入

整个扭结环共享“条纹频率”，但每个顶点可以有不同的颜色权重。前者用 uniform，后者用 attribute。可以把 uniform 想成一次绘制共享的配置，把 attribute 想成一张表里逐行不同的数据。

```js
const frequency = uniform(9);
app.gui.add(frequency, 'value', 1, 30, 1);
const bands = sin(positionLocal.y.mul(frequency).add(clock)).mul(0.5).add(0.5);
```

UI 修改 `.value`。相同节点输入保持不变，不需要重新编译材质。`clock` 也是 uniform，在 JS 动画回调中更新秒数。[UniformNode 文档](https://threejs.org/docs/pages/UniformNode.html)

## 为每个顶点准备三项数据

```js
const geometry = shape.geometry;
const position = geometry.attributes.position;
const bounds = geometry.boundingBox;
const width = bounds.max.x - bounds.min.x;
const data = new Float32Array(position.count * 3);
for (let i = 0; i < position.count; i++) {
  data[i * 3] = 1;
  data[i * 3 + 1] = 0.5 + (position.getX(i) - bounds.min.x) / width * 0.5;
  data[i * 3 + 2] = 1;
}
geometry.setAttribute('aTint', new THREE.BufferAttribute(data, 3));
```

`position.count` 是顶点数；一个顶点的 tint 有 R、G、B 三个分量，所以数组长度乘 3。`BufferAttribute(data, 3)` 告诉 Three.js 每三项是一条记录。这里使用定长浮点数组，方便上传 GPU。

扭结环是一个网格，示例直接给 `shape.geometry` 设置属性。根据几何体的实际 X 范围，把绿色权重从左到右映射到 0.5–1，使颜色变化连续且不受环体大小影响。

## 在节点中读取

```js
material.colorNode = mix(color('#326ca3'), color('#ffd58b'), bands)
  .mul(attribute('aTint', 'vec3'));
```

名字必须与 `setAttribute('aTint', ...)` 完全一致，类型 `vec3` 对应三项数据。在片元阶段读取时，通常会得到三角形顶点间插值后的结果，颜色就能连续变化。attribute 不是一像素一条记录。[AttributeNode 文档](https://threejs.org/docs/pages/AttributeNode.html)

第 13 课将使用 `InstancedBufferAttribute`：它按实例变化，而不是按每个顶点变化。先分清“一次绘制共享”“每个顶点”“每个实例”，再选择输入类型。

## 动手检查

以下实验以本课源码查看器中的完整 `script.js` 为起点，每次只做一项修改。修改文件后运行 `pnpm generate-previews` 并刷新预览；上一项要求恢复的代码先恢复，再进行下一项。

1. 暂停动画，拖动面板“所有顶点共享的频率”。条纹密度应变化，左右偏色仍然存在。
2. 在填充顶点数据的 for 循环内，把 `data[i * 3 + 1] = ...` 替换为 `data[i * 3 + 1] = 1;`。重新生成预览，左右 tint 差异应消失，因为所有顶点的三个分量都是 1。
3. 恢复原来的绿色分量公式。本课数组在初始化时生成，所以重新生成预览即可；若你在已经运行的页面中修改数组，则应设置 `shape.geometry.attributes.aTint.needsUpdate = true`，让 GPU 收到新数据。
