## 先认识标量和向量

标量是一个数，比如浓度 `0.7`。`vec2` 是两个数，比如 UV；`vec3` 是三个数，比如位置或 RGB。向量的 `.x/.y/.z` 与 `.r/.g/.b` 分量可以对应同一组数据。加一个标量会给所有分量加上这个数，乘一个标量会同时缩放所有分量。

示例左侧平面输出波形灰度，角色则输出基于波形的彩色带。先把“频率”从 1 拖到 24：频率越高，同一张表面上重复次数越多。

## 把 sin 的结果变成颜色

这里沿用第 02 课的 uniform。`frequency` 保存波形密度，`clock` 保存时间；两者都来自 JS，而 `wave` 是 GPU 根据它们计算的结果。源码中先定义输入，再连接表达式，最后在动画回调里更新时间：

```js
import { uv, uniform, sin } from 'three/tsl';
const frequency = uniform(8), clock = uniform(0);
const p = uv().mul(frequency);
const wave = sin(p.x.add(clock)).mul(0.5).add(0.5);
app.gui.add(frequency, 'value', 1, 24, 1).name('频率');
app.animate((seconds) => { clock.value = seconds; });
```

`clock` 是本课自己命名的 uniform，不是 Three.js 的 Clock 类。上面的回调是最小解释；完整源码同一个回调还会旋转角色，每课只有一个 `app.animate()` 更新回调，练习时保留其中其他更新。

`sin()` 输出 `[-1, 1]`。乘 `0.5` 后得到 `[-0.5, 0.5]`，再加 `0.5` 得到 `[0, 1]`。因此 `vec3(wave)` 能画出一条连续变化的灰度波。`clock` 改变输入的相位，视觉上就形成流动。

`sin()` 的周期是 `2π`，所以这里的 `frequency=8` 不是严格 8 条纹，而是在 UV 横向输入覆盖了 8 弧度。希望正好重复 N 次时，用 `uv().x.mul(N * Math.PI * 2)`。[MathNode 文档](https://threejs.org/docs/pages/MathNode.html)

## 为什么要 fract 和 smoothstep

```js
const bands = smoothstep(0.35, 0.65, fract(p.y.add(wave)));
material.colorNode = mix(color('#172889'), color('#fa785a'), bands);
```

`fract()` 返回小数部分，让线性增长值不断从 0 回到 1。`smoothstep(0.35, 0.65, x)` 在下界前输出 0，上界后输出 1，中间平滑过渡。它把锯齿状的数值变成有软边的色带。

| 运算 | 输入例子 | 输出直觉 |
| --- | --- | --- |
| `floor(x)` | 2.7 | 2，格子编号 |
| `fract(x)` | 2.7 | 0.7，重复进度 |
| `abs(x)` | -0.3 | 0.3，离零点多远 |
| `clamp(x, 0, 1)` | 1.4 | 1，限制范围 |
| `mix(a, b, 0.5)` | 两个颜色 | 两者中间色 |
| `smoothstep(a, b, x)` | a 到 b | 从 0 到 1 的平滑过渡 |

平滑边缘只是颜色过渡，不是几何体细分，也不等于抗锯齿。图案非常密集时仍可能闪烁，需要降低频率或引入基于导数的过滤。

## 注意数值安全

`pow(x, 2)` 常用来收紧遮罩，但非整数指数作用于负数可能产生无效值。`normalize()` 输入接近零长度时要避免除零。`smoothstep` 的下界应小于上界；想反转就用 `.oneMinus()`。这些问题通常会表现成黑块、闪烁或整个效果消失。

## 动手检查

以下实验以本课源码查看器中的完整 `script.js` 为起点，每次只做一项修改。修改文件后运行 `pnpm generate-previews` 并刷新预览；上一项要求恢复的代码先恢复，再进行下一项。

1. 暂停动画。在本课 `script.js` 中将 `material.colorNode = mix(...)` 这一整行替换为 `material.colorNode = vec3(wave);`。源码已导入 `vec3`，角色应显示连续灰度波形；随后替换为 `vec3(bands)`，应出现带软边的黑白条带。
2. 把 `const bands = smoothstep(0.35, 0.65, ...)` 的两个边界改成 `0.49, 0.51`，条带过渡应变窄。
3. 恢复彩色 `mix(...)` 表达式与原始边界。每次替换后重新生成预览，再通过面板暂停比较。
