## 本课要做什么

以统一生命周期组合扩张圆环、旋转和火花，生成可重新触发的魔法爆炸。对应目录中的 **Magic Explosions**。先观察结果，再读代码，最后修改参数验证理解。

## 爆炸是一段有限时间的动画

参考图里有多组紫色魔法能量环。本课先实现一个可以反复触发的爆炸对象。一个动画的时间可以拆成“年龄”和“进度”：

```js
const age = uniform(0);
const duration = 2.4;
const progress = age.div(duration).clamp(0, 1);
```

年龄以秒计算，进度位于 0 到 1。把所有外观都关联到进度后，点击重播只要把 age 设为 0。比为每个圆环分别创建计时器更容易保持同步。

## 扩张与淡出使用不同曲线

```js
material.positionNode = positionLocal.mul(progress.mul(2.5).add(0.1));
material.opacityNode = smoothstep(0, 0.08, progress)
  .mul(smoothstep(0.4, 1, progress).oneMinus());
```

开头很短的时间内出现，中后段慢慢淡出。网格顶点从很小的形状放大，6 个 torus 位于不同高度，稍微倾斜形成环绕感。这里加法混合适合亮能量环；重叠时更亮。[NodeMaterial](https://threejs.org/docs/pages/NodeMaterial.html)

圆环几何体不是粒子：它们有真正的三角形轮廓。火花则是小八面体，沿初始化的方向向外移动。本课只有 40 个火花，所以 JS 更新位置便于理解；数千个火花再考虑第 15、19 课的批量 GPU 方案。

## 发光来自两个步骤

能量环的颜色乘 3，生成高亮输入，再通过 Bloom 扩散到邻近像素。把 Bloom 去掉后能量环依然是亮色，但没有屏幕上的柔和光晕。[BloomNode](https://threejs.org/docs/pages/BloomNode.html)

示例依照公共外壳的 dt 推进年龄，暂停后年龄不变。“循环爆炸”关闭时，爆炸会完成并淡出；“重新触发”从起点播放。进度超过 1 后 clamp 保持结束状态。

## 动手检查

以下实验以本课源码查看器中的完整 `script.js` 为起点，每次只做一项修改。修改文件后运行 `pnpm generate-previews` 并刷新预览；上一项要求恢复的代码先恢复，再进行下一项。

1. 关闭“循环爆炸”，点击“重新触发”，确认每次都从小环开始，最终淡出。
2. 在 `script.js` 的 `material.opacityNode` 中，把 `smoothstep(0.4, 1, progress)` 改为 `smoothstep(0.8, 1, progress)`，亮环应保持更久。
3. 临时把 `const progress = age.div(duration).clamp(0, 1)` 改为 `const progress = age.div(duration)`。为了在淡出后仍看清缩放，再把 opacityNode 的完整赋值临时改为 `material.opacityNode = uniform(0.5)`；源码已导入 uniform。关闭循环，尺寸会在 duration 之后继续增长。完成后恢复 clamp 和原来的淡出表达式。

要扩展成多组爆炸，每组需要独立 age 与空间变换；共享静态几何体即可。
