## 场景创建工作流概述

第 49-53 课是本课程的最终项目：使用 Blender + Three.js 创建一个完整的 3D 场景。整个流程分为：

1. **Blender 建模**（本课）— 创建场景中的所有物体
2. **烘焙与导出**（第 50 课）— 将光照和材质烘焙到纹理
3. **导入与优化**（第 51 课）— 在 Three.js 中加载并优化
4. **添加细节**（第 52 课）— 粒子、动画和交互
5. **完成**（第 53 课）— 课程总结

## 场景规划

在打开 Blender 之前，先在纸上或脑中规划：

- **主题和风格** — 场景要表达什么？森林？室内？科幻？
- **物体清单** — 需要哪些物体？优先级如何？
- **光照方向** — 主光源从哪来？氛围是明是暗？
- **相机角度** — 用户从什么角度观看场景？
- **性能预算** — 目标设备是什么？总面数上限？

好的规划能节省大量时间。不要一开始就追求细节，先搭建整体框架。

## Blender 建模技巧

### 使用修改器提高效率

修改器（Modifier）是非破坏性的，可以在不改变原始几何体的情况下添加效果：

| 修改器                  | 用途     | 示例                         |
| ----------------------- | -------- | ---------------------------- |
| **Mirror**              | 对称建模 | 只建半个物体，另一半自动镜像 |
| **Array**               | 重复排列 | 栅栏、楼梯、柱子             |
| **Subdivision Surface** | 平滑表面 | 将低多边形变成圆滑表面       |
| **Bevel**               | 倒角     | 让边缘不那么锐利，更真实     |
| **Boolean**             | 布尔运算 | 挖洞、合并物体               |

### 组织场景层级

使用集合（Collection）管理复杂场景，类似文件夹：

```
Scene Collection
├── Environment
│   ├── Ground（地面）
│   ├── Walls（墙壁）
│   └── Sky（天空盒）
├── Props（道具）
│   ├── Furniture（家具）
│   ├── Decorations（装饰）
│   └── Plants（植物）
├── Lights（灯光）
└── Camera（相机）
```

良好的组织让导出时可以选择性地只导出需要的部分。

## 建模流程

### 第一步：粗模（Blockout）

用简单的立方体和圆柱体搭建场景的大致布局，确定比例和构图：

1. 添加 Cube → 缩放为地面
2. 添加更多基本形状代表墙壁、家具等
3. 调整比例和位置
4. 设置临时相机查看构图

### 第二步：细化模型

逐步将粗模替换为更精细的模型：

1. 对需要细化的物体进入编辑模式（Tab）
2. 使用挤出（E）、环切（Ctrl+R）、内插面（I）等工具
3. 保持合理的拓扑（尽量避免三角形和 N-gon）
4. 不需要过高的面数 — 目的是好看，不是面数竞赛

### 第三步：应用修改器

导出前应用所有修改器：

1. 选中物体
2. 在修改器面板点击 Apply（或 Ctrl+A → Apply Modifiers）
3. 或者直接在导出设置中勾选 "Apply Modifiers"

## UV 展开

UV 展开是将 3D 模型表面映射到 2D 平面的过程。如果模型需要纹理，UV 展开是必须的。

### 快速展开方法

1. 进入编辑模式（Tab）
2. 选择所有面（A）
3. UV → Smart UV Project
4. 检查结果，调整有拉伸的区域

### 手动展开（更精确）

1. 在编辑模式中选择边
2. 标记缝合线（Mark Seam）— UV 将沿缝合线分割
3. 选择所有面
4. UV → Unwrap
5. 在 UV Editor 中调整布局

### UV 展开检查

- 没有**拉伸**（正方形网格应该保持正方形）
- 没有**重叠**（除非有意为之）
- UV 岛之间的**间距**足够（避免纹理渗色）
- 重要区域**面积足够大**（给细节更多像素空间）

## 材质设置

使用 Blender 的 Principled BSDF（PBR 材质），导出后 Three.js 会保留大部分设置：

### 基本材质参数

| 参数       | 作用       | 典型值                     |
| ---------- | ---------- | -------------------------- |
| Base Color | 基础颜色   | —                          |
| Roughness  | 表面粗糙度 | 木头 0.7-0.9，金属 0.1-0.3 |
| Metalness  | 金属度     | 非金属 0.0，金属 1.0       |
| Normal     | 法线贴图   | 连接纹理到 Normal 插槽     |
| Emission   | 自发光     | 霓虹灯、屏幕等             |

### 材质命名规范

- 使用有意义的名称：`wood_dark`, `metal_brushed`, `glass_clear`
- 不要用默认的 `Material.001`, `Material.002`
- 相同材质的物体应该共享同一个材质

## 光照设置

光照对场景氛围至关重要：

1. **主光源**（Sun 或 Spot）— 提供主要照明和阴影方向
2. **填充光**（Area 或 Point）— 填补阴影区域
3. **环境光**（World 设置）— 整体环境照明
4. **背光/轮廓光** — 勾勒物体轮廓，增加层次感

## 模型检查清单

导出前逐一检查：

- [ ] 所有法线方向正确（蓝色朝外，不是红色）
- [ ] 已应用缩放（Ctrl+A → Scale）
- [ ] 已应用位置（Ctrl+A → Location，如果需要）
- [ ] 删除了隐藏的面和顶点
- [ ] 原点位置合理（通常在物体底部中心）
- [ ] 没有重叠的面（会导致渲染问题）
- [ ] 所有物体都有材质
- [ ] 集合组织清晰

:::tip
保持模型简单但有效。Web 3D 场景不需要电影级的面数。合理使用法线贴图来增加表面细节，实际面数控制在合理范围内。
:::
